Decisions from the V0 experiments

Evidence changed the implementation.

ADR-008Accepted in V0

Plant events define the site label

An audited round-level site field disagreed with events. Use the event-based outcome and keep the label derivation inspectable.

ADR-009Accepted in V0

Current inventory leads bomb reconstruction

A past drop location can be stale after pickup. Prefer a single current C4 carrier before a valid prior drop event.

ADR-010Accepted in V0

Preserve match groups and frozen folds

Repeated observations and match conditions are correlated. Keep a demo together and compare models on identical held-out observations.

ADR-011Accepted in V0

Economy does not enter selected V0

Current equipment-value features worsened probability quality in both tested model families.

ADR-012Accepted in V0

Select XGB-A5 as a development baseline

Defense improved nonlinear probability metrics. Keep horizon, geometry, motion, combat, and defense; record the model-selection boundary.

ADR-013Accepted in V0

Freeze development evidence before V1

Avoid repeatedly tuning against the same OOF results. Confirm future changes on untouched matches or a suitable nested design.

Decision: do not promote V1

A better pooled score is not sufficient when the improvement is tiny and match-level robustness is weak.

Preserve H2

Nested Site calibration improved probability quality and produced the best pooled V1 result. Keep it as a research finding.

Keep V0 selected

H2 won log loss on only 9/20 matches and its equal-match bootstrap interval crossed zero. T0 also failed. No sequence model is justified.

V2 integrity decisions

Decisions made before any confirmation-model scoring.

ADR-008

Valid in-round plant events are canonical A/B site evidence.

Event bombsite achieved 298/298 agreement with planter place in D_CONFIRM.

ADR-009

Round-level bomb_site is not canonical A/B truth.

It reported B for all 188 independently verified A-site plants in D_CONFIRM.

ADR-010

Ghost plant events cannot create labels.

Plant tick must fall inside the authoritative round interval.

ADR-011

Unresolved plant site excludes the round.

Never guess A/B from conflicting metadata.

ADR-012

Missing snapshot/bomb state excludes only the affected observation when explicitly allowed by the V2 confirmation adapter.

ADR-013

No future information may repair an earlier observation.

Future pickup/drop/plant evidence is forbidden for reconstruction at time t.

Decision from V2 confirmation

Independent evidence closes the V2 model-selection question.

ADR-V2-001 Accepted after confirmation

Keep V0 as the primary model

Corrected development evaluation already favored V0 on the primary three-class log-loss metric. Untouched D_CONFIRM preserved the same direction: V0 0.835090 versus H2 0.836643.

H2 is retained as a documented research challenger, but there is no promotion.
